# Luxury Listing Brochure

Premium editorial brochure for Jason Lim · Compass.

## Stack
- React + Vite + TypeScript
- Tailwind CSS v4
- Framer Motion
- qrcode.react
- Print CSS → PDF (Letter)

## Develop
```bash
npm install
npm run dev
```

## Build for Hugging Face static Space
```bash
npm run build
# copy dist/* to Space root (or spaces/listing-brochure-studio/static)
```
