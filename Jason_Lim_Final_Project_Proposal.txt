Subject: Final Project Proposal — AI Luxury Listing Brochure Studio

Hi,

For my final project I will build an AI-powered luxury listing brochure generator for Silicon Valley real estate, deployed as a Hugging Face Space and aligned with my Compass practice site (jasonlimrealty.com).

The app takes a Compass, Zillow, or Redfin listing URL (or manual photos and facts), then uses LLMs and structured prompts to generate editorial brochure copy: headlines, property narrative, lifestyle pull quotes, and feature descriptions. The output is a multi-section, magazine-style interactive brochure with print/PDF export—not a generic flyer.

Core LLM work includes prompt engineering for luxury tone (Compass / Sotheby’s style), grounding copy in listing facts and photo context, optional polishing via Hugging Face Inference, and a planned AI home-estimate narrative module with confidence-style language for sellers. I will also document failure modes such as incomplete portal data and how the product falls back to editable facts.

I will demo a working MVP: URL/manual intake → AI-assisted copy → branded brochure UI → Print/PDF. This showcases practical LLM application, Hugging Face deployment, and product thinking for a real-world real estate use case.
